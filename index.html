Grammar Used
LL(1)
Program   → int main ( ) Block
Block     → { StmtList }
StmtList  → Stmt StmtList | ε
Stmt      → Decl ; | Assign ; | IfStmt | Print ; | Return ;
Decl      → int id Init
Init      → = Expr | ε
Assign    → id = Expr
IfStmt    → if ( Cond ) Block
Print     → print ( Expr )
Return    → return Expr
Expr      → Term Expr'
Expr'     → + Term Expr' | - Term Expr' | ε
Term      → Factor Term'
Term'     → * Factor Term' | / Factor Term' | ε
Factor    → id | num | ( Expr )
Cond      → Expr RelOp Expr
RelOp     → > | < | == | != | >= | <=
